# 从 49 条模糊规则到一张控制查询表

[下载 ZIP](https://github.com/libai1943/FuzzyTableGeneration/archive/refs/heads/main.zip) · [从这里开始](#运行与查表) · [阅读指南](#对照源码读推理过程) · [引用](#教材与实现)

一个控制器读到误差 `E` 和误差变化 `EC`，应该输出多大的控制量 `U`？这个 MATLAB 教学示例把 7 × 7 条语言规则展开为 覆盖 13 × 13 种量化输入组合的整数控制查询表。可以直接查看最终表，也可以逐段读脚本，跟踪一条规则如何参与推理。源码注明算例对应《智能控制理论及应用》第 39 页。

## 运行与查表

在 MATLAB 中打开仓库目录，然后运行以下命令。脚本开头的 `clear all` 和 `close all` 会清空当前工作区并关闭图窗，适合从空会话开始。

```matlab
GenerateFuzzyTable
size(Fuzzy_Table)                % [13 13]
E = -2; EC = 3;
U = Fuzzy_Table(E + 7, EC + 7)   % 输入值 -6:6 对应 MATLAB 下标 1:13
```

输出留在工作区，命令窗口同时显示整张表。行对应第一个输入，列对应第二个输入。如果想看规则面，可以继续执行：

```matlab
imagesc(-6:6, -6:6, Fuzzy_Table); axis xy; axis image; colorbar
xlabel('EC'); ylabel('E'); title('控制查询表 U(E, EC)')
```

## 对照源码读推理过程

| 脚本中的变量 | 默认尺寸 | 在计算中扮演的角色 |
| --- | --- | --- |
| `rule` | 7 × 7 | 每行、每列各对应一个输入语言值。元素是输出语言值的编码，1 至 7 依次代表 NB、NM、NS、Z、PS、PM、PB。 |
| `input_1_membership`、`input_2_membership`、`output_2_membership` | 各 7 × 13 | 行是语言值，列是从 −6 到 +6 的整数档位，元素是该档位对语言值的隶属度。 |
| `R` | 169 × 13 | 对每条规则取最小值形成关系，再对 49 条规则逐元素取最大值聚合。每行对应一组输入档位。 |
| `Cd` | 1 × 13 | 为两个量化输入各选取最大隶属度语言值，再与关系矩阵作最大–最小合成，得到输出隶属度。 |
| `Fuzzy_Table` | 13 × 13 | 对 `Cd` 做加权平均，再用 `round` 取整，得到可直接查询的控制量。 |

先只改 `rule` 的一个元素并重画规则面，观察哪些输入档位的输出随之改变。若修改隶属度矩阵，需确保每个档位都被覆盖，使加权平均的分母大于零。相邻语言值出现相同最大隶属度时，MATLAB 的 `max` 取先出现的语言值，复算表项时也要采用同样的规则。
